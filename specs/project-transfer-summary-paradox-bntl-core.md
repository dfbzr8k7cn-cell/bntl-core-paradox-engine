## RealitySignal

For each active channel i at time t:

Feature groups:
- H_i(t): HumanLayer features
- M_i(t): MythicLayer features
- C_i(t): CosmicLayer features
- Cog_i(t), Emo_i(t), Cre_i(t): cognitive, emotional, creative signatures
- Dest_i(t), Align_i(t), World_i(t), Cycle_i(t): context anchors
- Filters_i(t): measured spectrum filters
- Reson_i(t): resonance channels
- Anom_i(t): anomaly layers

All terms are normalized into unitless features using rolling normalization: N(·), z-score, or robust z-score using median/MAD.

Gain:
G_i(t) = N(H_i + M_i + C_i) ⊙ N(Cog_i + Emo_i + Cre_i) ⊙ N(Dest_i + Align_i + World_i + Cycle_i)

Denominator:
D_i(t) = ε + N(Filters_i + Reson_i + Anom_i)

Per-channel signal:
R_i(t) = G_i(t) ÷ D_i(t)

Global fused signal:
RealitySignal(t) = Σ_i w_i(t) · R_i(t)

Weight rules:
- w_i(t) is between 0 and 1
- all weights sum to 1
- no single channel can dominate beyond configured caps
- weights are adaptive but constrained by safety and stability

Attachment update:
Δ_A(t) = w_A(t) · R_A(t)

RealitySignal(t+) = RealitySignal(t) + Δ_A(t)

No formula rewrite. Attachments add bounded delta. All attachments require provenance. Evolution is additive only.
