# BNTL Unified App Spine

## Master System

BNTL Core · Paradox Engine is the master system.

## Module Rule

Every app or worker lane is a module, lab, workspace, or support console. Nothing should become a disconnected product.

## Hub Structure

- Master app: BNTL Core · Paradox Engine — Unified Master Build
- Visual/spec hub: Canva folder
- Storage/database hub: Google Drive Operating Database
- Source-control hub: GitHub repo
- Prototype lane: Replit when available

## Anti-Fragmentation Rules

- No new app without a defined module role.
- Every worker output feeds back to the master build.
- Every mock or seed dataset is labeled Sample UI Data.
- Every source must preserve provenance and truth status.
