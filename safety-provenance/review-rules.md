# Safety + Provenance Review Rules

## Core Rules

- Preserve source context
- Use truth labels consistently
- Keep sample data visibly marked
- Do not expose secrets in repo files
- Do not promote candidates as live without review
- Keep exports reviewable before use

## Review Gates

- Source review
- License review
- EventEnvelope review
- Validation review
- Provenance review
- Export review
- Manual approval

## Required Fields for Review

- source_url
- license
- truth_label
- sample_flag
- confidence
- quality_score
- freshness_status
- provenance_hash
- transform_params
