## Safety Correction for Targeting Language

Some reference images contain labels such as target, hostile, mark target, target acquired, and cycle target.

For Paradox Engine + BNTL Core public/product UI, avoid human-targeting or hostile-person labels.

Use safer operator language:

- Focus Lock
- Point Lock
- Object Lock
- Signal Lock
- Vision Lock
- Source Lock
- Track Object
- Inspect Source
- Cycle Focus
- Clear Lock
- Mark Point of Interest
- Navigation Focus

Do not label real people as hostile, ally, immune, target, or acquired.

If camera/person overlays ever exist, they must be permission-based, privacy-preserving, non-identifying, and used for accessibility, navigation, safety review, or generic object/person presence detection only.

No biometric identification. No face recognition. No person targeting. No threat classification of real people.
