# BNTL HUD + Atlas UI Blueprint

## Visual Direction

- Dark cosmic interface
- Atlas-centered layout
- Earth, Cosmic, Planetary, Human, Device, Mythic, and Anomaly layers
- Mars is a planetary module, not the entire system
- Safety and source panels stay visible without becoming the whole identity

## HUD Layout

- Center: live-style tile or atlas viewport
- Left: quick stats and mode state
- Right: SourceList, EventTimeline, and Export panel
- Bottom: command controls
